## 摘 要

随着大型语言模型（Large Language Models, LLMs）在软件工程自动化领域的深入应用，基于大语言模型的多智能体系统（Multi-Agent Systems, MAS）结合检索增强生成（Retrieval-Augmented Generation, RAG）已成为自动编写大型企业软件项目《详细设计规格书》等复杂工程文档的核心技术范式。然而，在真实工业工程落地中，现有 RAG 文本切片与检索机制面临着**双重维度的“静态切片与动态异构需求之间的核心矛盾”**：一方面，在**文档维度**上，企业软件工程文档（需求规格书、技术协议、接口规约、数据库字典及会议纪要）是包含密集二维表格与多级标题树的异构半结构化制品，传统固定窗口切分、标点递归切分或仅依赖相邻句嵌入余弦距离的通用语义切片极易将表头与数据行拦腰斩断、破坏章节内聚性并丢失源文档出处谱系，而依赖生成式大模型重写全文的原子命题或递归摘要切片又面临严峻的长文档计算超时与摘要微幻觉风险；另一方面，在**查询与角色维度**上，多智能体系统中的顶层协调智能体、模块接口智能体与底层数据库/约束核查智能体对上下文抽象粒度存在天然的结构性分化（宏观连贯段落 vs. 跨块层次消歧上下文 vs. 高信噪比原子表格行），传统索引后全局固化的单一检索粒度或机械硬作用域隔离无法同时兼顾各角色的检索精度与子会话上下文词元（Token）经济性。

围绕上述双重矛盾，本文确立了**“文档级动态结构感知切片 + 查询级面向智能体角色动态检索粒度路由”**的双层协同优化技术路线，依次开展了以下三项核心研究工作：

第一，**提出面向企业工程文档的结构与关键信息感知自适应语义切片算法（Structure- and Key-Information-Aware Adaptive Semantic Chunking, SEAC）**。定义了携带稳定源单元出处标识（`Unit ID`，精确到文档区块号与表格行号）的零改写文本单元表示与**表头显式绑定渲染公式**；首次将相邻单元稠密语义距离、文档语法结构转移分、工程关键信息词表密度变化分以及同节/同表连续性惩罚统一于确定性透明边界打分模型中；进而提出了根据每份文档自身表格行占比与标题占比动态调节的**文档级自适应切分阈值 $\theta_D$**，以及“四档容量受保护父块 + 独立表格行子块”的层次化索引构建与软融合检索算法。在包含 10 个真实工业软件工程项目、89 份文档、66,981 个检索单元、2,670 个盲审标注边界（$\kappa \in [0.761, 0.892]$）与 225 道经人工及隐私审核问答对的冻结工业基准上，严格遵循开发/验证/锁定测试三段防泄漏评估协议开展的对比实验表明：在锁定测试集（`P04`–`P09`）上，SEAC 取得了 **$0.5673$ 的边界切分 F1**（精确簇置换检验 $p = 0.03125$）以及 **$0.7937$ 的单元级 Unit MRR、$0.9520$ 的 Hit@5 和 $0.7623$ 的片段级 Span MRR**，全面超越固定窗口、递归切分、通用语义切片以及 LangChain、LlamaIndex 官方切片器等 8 种外部基线。

第二，**提出基于可共享单一索引的面向智能体角色动态检索粒度选择方法（Role-Aware Dynamic Retrieval Granularity Selection for MAS, MAS-DRG）**。基于第 3 章消融实验揭示的“全局固定父块融合权重（$\alpha=0.35$）在原子表格行查询上稀释信噪比、但在跨接口参数查询上不可或缺”的实证规律，将详细设计多智能体系统的五类智能体角色形式化映射为**执行层精确事实型（$T_{\text{atomic}}$）**、**模块层层次上下文型（$T_{\text{hier}}$）**与**协调层上下文概述型（$T_{\text{macro}}$）**三类信息需求模型。突破了传统多粒度方案需重复构建 $N$ 套冗余物理索引库的高成本局限，提出在 SEAC 单一父子层次化索引上按智能体角色先验动态查表路由**排序融合权重 $\alpha \in [0, 1]$** 与**上下文返回模式 $m \in \{\text{Child-Only}, \text{Hybrid}, \text{Parent-Only}\}$** 的零延迟架构。由开发/验证集标定并在锁定测试集上盲测的结果证明：MAS-DRG 精度优先策略将锁定测试集整体 Unit MRR 进一步提升至 **$0.8416$（Hit@1 达 $0.7520$，Span MRR 达 $0.8195$）**，较 SEAC 静态默认配置显著提升 **$+0.0479$（相对提升 $+6.04\%$，在全部 6 个锁定测试项目上取得 6 胜 0 负，精确簇置换检验 $p = 0.03125 < 0.05$）**，召回优先策略 Hit@5 达到 **$0.9600$**；同时将单次查询平均返回的上下文 Token 开销从静态父块返回的 $1,061.1\text{ tokens}$ 大幅压缩至 **$681.3\text{ tokens}$（降低 $35.8\%$，较固定窗口降低 $72.2\%$）**。

第三，**完成在企业级多智能体详细设计文档生成系统中的检索服务设计与离线案例验证**。剖析了由 `Multi-Agent-DetailedDesign` 应用层、`Multi-Agent-Framework` 核心运行时层与 `binary-tools`（Typst / PlantUML / Mermaid）编译工具层构成的三层系统架构及 `session_create` / `session_query` 父子会话上下文隔离机制；设计了标准化的 `rag_query` 可追溯知识检索服务接口，并通过 5 个跨层级真实工业智能体请求的离线对比实验与系统编译产出展示，验证了本文方法在消除跨页表格表头剥离、解决跨接口同名参数歧义及实现源文档单元级可追溯审计方面的工程实用价值。

**关键词**：检索增强生成；动态语义切片；多智能体系统；检索粒度路由；软件工程文档；可追溯性

## Abstract

With the rapid advancement of Large Language Models (LLMs) in software engineering automation, integrating LLM-based Multi-Agent Systems (MAS) with Retrieval-Augmented Generation (RAG) has emerged as a cornerstone paradigm for automatically authoring complex industrial engineering artifacts such as *Detailed Design Specifications*. Nevertheless, in real-world enterprise deployments, existing RAG chunking and retrieval mechanisms confront a **dual-dimensional contradiction between static chunking and dynamic heterogeneous demands**. Along the **document dimension**, enterprise software engineering documents (requirements specifications, technical agreements, API specifications, database dictionaries, and meeting minutes) are heterogeneous semi-structured artifacts densely populated with two-dimensional tables and multi-level heading trees. Conventional fixed-window splitters, recursive punctuation splitters, and generic embedding-similarity chunkers frequently sever table headers from data rows, disrupt section cohesion, and erase source provenance lineage, whereas generative LLM-based proposition or recursive summarization chunkers suffer from severe long-document execution timeouts and abstractive micro-hallucinations. Along the **query and role dimension**, distinct agent roles within a hierarchical MAS—ranging from top-level coordinators and module/interface designers to execution-level database and constraint verifiers—exhibit structurally divergent context granularity requirements (macro coherent paragraphs vs. cross-chunk hierarchical disambiguation context vs. high-SNR atomic table rows). Globally static post-indexing retrieval granularities or brittle hard scoping fail to simultaneously optimize retrieval accuracy and sub-session context token efficiency across heterogeneous roles.

To resolve this dual contradiction, this thesis establishes a two-tier synergistic optimization framework combining **Document-Level Dynamic Structure-Aware Chunking** and **Query-Level Role-Aware Dynamic Retrieval Granularity Routing**, comprising three core research contributions:

First, we propose **Structure- and Key-Information-Aware Adaptive Semantic Chunking (SEAC)** for enterprise software engineering documents. We formulate a zero-rewrite text unit representation carrying immutable provenance identifiers (`Unit ID` down to specific document blocks and table rows) alongside an **explicit header-bound row rendering formula**. SEAC integrates adjacent dense semantic cosine distance, structural section/table-group transitions, domain key-information density shifts, and intra-section/intra-table continuity penalties into a transparent, deterministic linear boundary scoring model. Furthermore, we introduce a **document-adaptive threshold $\theta_D$** dynamically calibrated according to each document's table-row ratio and heading ratio, coupled with a four-tier capacity-protected parent chunk builder and header-bound table-row child index. Evaluated under a strict three-way anti-leakage protocol (Development / Validation / Locked Test) across a frozen industrial benchmark of 10 enterprise software projects, 89 documents, 66,981 retrieval units, 2,670 doubly annotated boundary pairs ($\kappa \in [0.761, 0.892]$), and 225 human- and privacy-audited QA pairs, SEAC achieves a **Boundary F1 of $0.5673$** ($p = 0.03125$), a **Unit MRR of $0.7937$, a Hit@5 of $0.9520$, and a Span MRR of $0.7623$** on the unseen locked test split (`P04`–`P09`), consistently outperforming 8 external baselines including fixed-window, recursive, generic semantic, and official LangChain and LlamaIndex splitters.

Second, we propose **Role-Aware Dynamic Retrieval Granularity Selection for Multi-Agent Systems (MAS-DRG)** built upon a single shareable hierarchical index. Motivated by our ablation finding that a globally fixed parent-child fusion weight ($\alpha=0.35$) dilutes signal-to-noise ratio on atomic table-row queries yet remains indispensable for cross-section API parameter disambiguation, we model the five specialized agent roles in the detailed design MAS into three distinct information demand profiles: **Atomic Fact ($T_{\text{atomic}}$)**, **Hierarchical Context ($T_{\text{hier}}$)**, and **Macro Overview ($T_{\text{macro}}$)**. Overcoming the $N\times$ storage overhead of multi-index architectures, MAS-DRG decouples and dynamically routes the **ranking fusion weight $\alpha \in [0, 1]$** and the **context return mode $m \in \{\text{Child-Only}, \text{Hybrid}, \text{Parent-Only}\}$** at query time via an $O(1)$ role-prior lookup table on the single SEAC index. Calibrated solely on the development/validation split (`P01`–`P03`) and evaluated blindly on the locked test split (`P04`–`P09`), the precision-oriented MAS-DRG policy elevates overall **Unit MRR to $0.8416$ (Hit@1 of $0.7520$, Span MRR of $0.8195$)**, achieving a statistically significant gain of **$\Delta\text{MRR} = +0.0479$ ($+6.04\%$ relative improvement, winning 6 out of 6 locked projects with exact cluster randomization $p = 0.03125 < 0.05$)** over the static SEAC default while outperforming all globally static configurations; the recall-oriented policy reaches a **Hit@5 of $0.9600$**. Simultaneously, on-demand context return modes compress average per-query Top-5 context consumption from $1,061.1\text{ tokens}$ ($2,535.3\text{ tokens}$ for fixed windows) down to **$681.3\text{ tokens}$ (a $35.8\%$ reduction over static SEAC and a $72.2\%$ reduction over fixed windows)**.

Third, we present the **architectural integration design and offline industrial case validation within the Enterprise Multi-Agent Detailed Design Generation System**. We analyze the three-tier engineering architecture (`Multi-Agent-DetailedDesign`, `Multi-Agent-Framework`, and Rust-based `binary-tools` with Typst/PlantUML/Mermaid) and its `session_create` / `session_query` hierarchical sub-session isolation mechanism. We design a standardized, provenance-preserving `rag_query` service interface and conduct qualitative and quantitative case studies across five representative multi-layer agent requests, demonstrating its effectiveness in eliminating table header stripping, resolving cross-API parameter collisions, and enabling unit-level auditable software engineering document generation.

**Keywords**: Retrieval-Augmented Generation; Dynamic Semantic Chunking; Multi-Agent Systems; Retrieval Granularity Routing; Software Engineering Documents; Traceability
