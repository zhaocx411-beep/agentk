# 第 1 章 绪论

## 1.1 研究背景与意义

### 1.1.1 大语言模型的知识局限与检索增强生成的兴起

近年来，以 Transformer 自回归架构为底座的大型语言模型（Large Language Models, LLMs）在自然语言理解、代码合成、逻辑推理与多步任务规划等领域取得了突破性进展，推动人工智能范式从面向单一任务的判别式建模迈向通用生成式智能。然而，当大语言模型从开放域通用对话走向企业级严肃工程应用（如工业软件系统研发、金融合规审查、法律文书起草及政务统计核查）时，仅依赖预训练参数化记忆（Parametric Memory）的内生局限性便暴露无遗：

1. **私有领域知识盲区与长尾缺失**：大语言模型的预训练语料主要来源于公开互联网文本，无法覆盖企业内部受控流转的非公开工程资产（如特定工业项目的《技术协议》《需求规格说明书》《详细设计规格书》《数据库表结构字典》及《需求调研会议纪要》）。面对特定企业软件系统的内部接口规范或专有数据字典，模型缺乏事实依据。
2. **知识截止（Knowledge Cutoff）与动态演化滞后**：企业软件工程文档在项目生命周期内处于持续修订与版本演进之中。通过全量微调（Fine-Tuning）将新增或变更的工程文档注入模型权重，不仅计算成本高昂、更新周期漫长，而且极易引发灾难性遗忘（Catastrophic Forgetting）。
3. **长上下文“中间信息迷失”与注意力分散**：即便近期大模型将物理上下文窗口扩展至数十万乃至上百万词元（Tokens），直接将整卷宗文档塞入提示词的无检索模式（Open-Book）仍面临严峻的“中间迷失（Lost in the Middle）”效应[11]。如 Duarte 等人[23]在长篇文学叙事基准 GutenQA 上的实证所示，直接将整本书输入长上下文窗口的无检索模式准确率仅为 $37.76\%$，而结合动态语义切片的检索增强模式可将准确率大幅提升至 $88.89\%$；Zheng 等人[56]关于大语言模型注意力头机理的综述亦从模型内部可解释性角度证实，过长且混杂无关噪声的输入会显著分散负责指代消解与事实召回的特定功能注意力头（Retrieval & Induction Heads）激活分布。
4. **事实性幻觉（Hallucination）与不可审计性**：在缺乏确定性外部证据约束时，生成式模型倾向于依赖统计共现概率拼接出表面流畅但事实错误的伪造参数、虚假数据库字段或不存在的接口路径；同时，纯粹的参数化生成无法提供精确到源文档具体章节或表格行的出处谱系（Provenance Lineage），难以满足企业级软件工程对可追溯性（Traceability）与人机协同审计（Human Oversight）的刚性治理要求。

为克服上述局限，Lewis 等人[1]提出的**检索增强生成（Retrieval-Augmented Generation, RAG）**将预训练生成模型与外部非参数化知识库（Non-Parametric Memory）有机结合，确立了“离线文档解析与索引（Indexing）—在线相关性检索（Retrieval）—基于证据的受控生成（Generation）”三阶段范式。通过在推理阶段动态检索与当前任务相关的外部文档片段并注入模型上下文窗口，RAG 不仅大幅降低了领域幻觉率，更为生成结果构建了可核查的外部证据链，已成为当前企业级大模型应用落地的核心基础设施。

### 1.1.2 多智能体系统在复杂文档生成任务中的应用

随着企业数字化转型的深入，工业现场（如钢铁冶金、智慧能源、船舶建造与港口装备管理）对大型软件系统的设计研发效率提出了更高要求。其中，《详细设计规格书》作为连接《需求规格说明书（SRS）》与底层代码实现的核心工程桥梁，通常篇幅长达数百页，涵盖总体架构设计、数十个业务子模块的功能描述、上百个对外与内部服务接口定义（API）、数百张物理数据库表结构说明（数据字典）以及跨系统业务协同流程。

面对如此宏大且结构严密的文档撰写任务，单次或单智能体大语言模型调用受制于输出窗口长度上限、长上下文注意力退化以及多维指令遵循能力的衰减，无法直接生成达到工业交付标准的完整设计文档。为此，学术界与工业界广泛引入**基于大语言模型的多智能体系统（LLM-based Multi-Agent Systems, MAS）**[43-46]。通过模仿人类软件工程团队的分工协作模式，多智能体系统将复杂的详细设计文档生成任务解构为层级化的角色协作网络——由顶层协调智能体（Coordinator / Detailed Design Agent）负责全局大纲规划与跨章调度，由章节概述智能体（Overview Agent）负责架构与流程综述，由模块与接口智能体（Module / Interface Agent）负责具体功能模块与接口契约设计，并由底层数据库与规格核查智能体（Database / Constraint Agent）负责表结构字典与非功能性指标的精确落地。在每个智能体的“推理与行动（ReAct）”[43]循环中，RAG 知识检索服务构成了各智能体从前期项目文档库（技术协议、需求规格书、历史纪要等）中获取事实依据的核心感知通道。

### 1.1.3 静态切片与多智能体动态异构需求之间的核心矛盾

尽管“多智能体系统 + 检索增强生成（MAS + RAG）”在架构上极具潜力，但在真实企业工程落地实践中，“知识检索的准确性与上下文适配度”却成为制约多智能体决策质量与下游文档生成成功率的首要技术瓶颈。遵循信息检索领域的“垃圾进，垃圾出（Garbage In, Garbage Out）”铁律，RAG 系统的性能上限在很大程度上由其最前端的**文本切片（Text Chunking / Document Segmentation）**与**检索粒度选择（Retrieval Granularity Selection）**所决定[4, 5, 22]。

深入剖析现有 RAG 切片机制与企业级多智能体文档生成场景的耦合过程，可以发现当前技术体系面临着**双重维度的“静态切片与动态异构需求之间的根本矛盾”**：

1. **文档维度：静态单层切片割裂文档原生结构与语义完备性的矛盾**
   主流 RAG 框架（如 LangChain[17] 与 LlamaIndex[18]）默认采用固定 Token 窗口切分、递归字符分隔符切分或仅依赖相邻句嵌入余弦距离的通用语义切片。传统定长或简单标点切分先物理截断文本，再将各切片作为独立同分布（i.i.d.）样本输入编码器并进行均值池化，不仅破坏了跨段落共指消解关系[15]，更无视了企业软件工程文档中二维表格、多级编号标题树与合同条款的原生层级结构，极易将表头与数据行拦腰斩断（导致后半部分数据行沦为“无主孤魂”），或将标题与其统领的首段正文剥离。即便近期研究尝试引入生成式大模型提取原子命题（如 Dense X Retrieval[22]）或构建递归聚类摘要树（如 RAPTOR[7]），在真实工业长文档上仍面临严峻的**计算超时（Timeout）、底层分词库内存溢出（Memory Error）[57]以及生成式摘要节点微幻觉（如 RAPTOR 人工抽检节点中存在约 $4\%$ 的微幻觉率）[7, 48]**等工程与合规瓶颈，且生成式改写破坏了工程文档对条款原文与表格行出处谱系（Provenance Lineage）的刚性保真要求。
2. **查询与角色维度：同质化检索忽视多智能体系统角色异质性与子会话隔离需求的矛盾**
   跨数据集的受控对比实验表明，**没有任何单一静态粒度能够在所有查询条件与文本体裁下全局占优**[22, 23, 58]。例如，原子命题粒度在百科事实问答基准 FactoidWiki 上使稠密检索器 Recall@5 取得 $10\% \sim 25\%$ 的相对提升[22]，但迁移至长篇叙事基准 GutenQA 时其 Recall@20（$55.54\%$）却远低于动态变长切片 LumberChunker（$77.92\%$）甚至固定递归切分（$74.35\%$）[23]。在多智能体详细设计系统中，现有自适应 RAG 路由（如 Adaptive-RAG[33]、A-RAG[51]）大多仅依据单轮孤立问句的表面复杂度（Query Complexity）切换检索步数，未能感知多智能体工作流中规划、架构、接口编码、数据库与合规审查等**异构角色对上下文抽象层级的差异化偏好**：
   - 底层执行层智能体（如数据库设计智能体、规格约束核查智能体）需要的是**高信噪比原子事实（Atomic Facts）**，如特定表名下某一个字段的数据类型或某一条性能指标。若混入整章父块分数或返回数百 Token 的整表文本，不仅会稀释目标行的向量匹配度，还会挤占子会话上下文窗口；
   - 模块层智能体（如接口设计智能体）需要的是**层次关联上下文（Hierarchical Context）**，必须联合“所属接口小节父块语义”与“具体参数行子块语义”才能消除跨接口同名参数歧义；
   - 顶层协调与章节智能体（如总体设计智能体、章节概述智能体）则需要**宏观连贯段落（Macro Overview）**以把握全局架构脉络。
   此外，近期针对智能体子会话隔离的研究（如 NativeScope[50]）表明，单纯依赖自动 Top-1 锚点定位的机械硬作用域隔离（Hard Scoping）会直接继承前端定位接口误差，导致记忆召回率跌至 $35.50\%$，亟需结合角色感知的软性多粒度父子回退机制[49, 50]。

简言之，**企业工程文档内部结构的高度异构性**呼唤一种无需生成式重写、零幻觉且能感知结构与关键信息密度的**文档级动态切片算法**；而**多智能体协作角色的信息需求异构性与子会话隔离需求**则呼唤一种能够在查询阶段按角色自适应调节排序权重与返回模式的**查询级动态检索粒度选择机制**。

### 1.1.4 理论意义与应用意义

围绕上述双重矛盾展开深入研究，兼具重要的学术理论价值与工程应用价值：

* **理论意义**：
  1. **拓展半结构化工程文档的无幻觉确定性语义切片理论**：突破现有语义切片仅依赖句向量余弦距离或依赖昂贵黑盒大模型在线重写的局限，将文档语法树结构保护、领域关键信息密度跃迁、同节/同表连续性惩罚以及基于文档组成比例（表格行率与标题率）的动态阈值融为一体，建立零改写幻觉、计算高效且端到端保留出处谱系的文本单元与父子分块模型。
  2. **实现 RAG 优化范式从“单轮问句复杂度路由”向“多智能体角色感知粒度路由”的跃迁**：针对检索粒度的多目标权衡困境[57, 58]，揭示全局固定父子融合权重在不同智能体角色任务上的性能分化机理，提出在单一层次化索引上通过联合角色先验动态调节父子融合权重 $\alpha$ 与上下文返回模式的新范式，克服硬作用域隔离的级联召回退化问题[50]。
  3. **建立高可信的工业级 RAG 切片评测与聚类统计推断方法学**：针对企业文档跨文件条款复用导致的单一金标准失效问题，提出多源等价证据集（Evidence Equivalence Set）与单元级/片段级双重评估准则，并引入以独立工程项目为簇的分层 Bootstrap 置信区间[20]与精确簇置换检验，为工业界开展防泄漏、可验证（PEP-AI）[58, 59]的 RAG 组件评测提供严谨的方法学范本。
* **应用意义**：
  1. **直接攻克多智能体详细设计文档生成系统的检索瓶颈**：为《多智能体详细设计文档自动生成系统》提供高准确度、低噪声且来源可查的证据检索底座，有效避免因表头丢失或跨接口张冠李戴引发的下游设计错误。
  2. **兼顾企业级大模型系统的检索质量、Token 经济性与治理合规性**：呼应 Hua 与 Xiao[49]（2026）关于智能体子任务按切片精准投递与任务局部复用的最新发现，通过单索引角色动态路由，在不增加多倍向量库存储开销的前提下，将单次查询平均上下文 Token 消耗大幅压缩 $35.8\%$（较固定窗口降低 $72.2\%$），同时确保每一条返回证据均携带精确到源文档块与表格行的不可篡改出处标识。

## 1.2 国内外研究现状

检索增强生成（RAG）与多智能体系统（MAS）正经历从“启发式定长切分 + 静态单次检索”向“上下文感知边界检测 + 查询复杂度与智能体状态自适应路由”的深刻演进。本节按“**固定启发式切片 $\to$ 语义与结构感知动态切片 $\to$ 查询自适应与多粒度路由 $\to$ 智能体角色感知记忆、上下文工程与可验证评测**”的逻辑递进脉络，系统评述 2020–2026 年间国内外代表性研究成果。

### 1.2.1 半结构化文档解析与语义感知文本切片研究现状

文本切片决定了外部知识转化为向量索引的基本颗粒度。围绕如何打破传统机械切分导致的指代消解断裂与结构丢失，国内外学者沿着三条核心技术路线展开了深入探索：

1. **原子命题级与递归聚类树多粒度索引路线（Dense X Retrieval、RAPTOR、SPIKE、RAIDD）**
   传统 Naive Chunking 先按固定窗口或标点切分文本（如 LangChain `RecursiveCharacterTextSplitter`[17] 与 LlamaIndex `SentenceSplitter`[18]），再将各切片作为独立样本编码，极易切断跨句指代。针对此问题，Chen 等人[22]（EMNLP 2024）提出了 **Dense X Retrieval**，利用生成模型将语料解析为满足“语义独立、最小不可分、完成指代消解与背景自包含”三大原则的**原子命题（Propositions）**，并构建了包含 100 词段落、句子与命题三层粒度的 FactoidWiki 基准。实验表明，在严格受限的 Token 预算（$l = 100$ 或 $500$）下，命题粒度在 EntityQuestions 上使 DPR 和 ANCE 的 Recall@5 取得 $17\% \sim 25\%$ 的相对提升（DPR 提升达 $25\%$），在 SQuAD 上使 TAS-B 和 GTR 的 Recall@5 提升 $10\% \sim 16\%$，且四个检索器的下游问答 EM@100 较段落级平均提升 $19\% \sim 26\%$。与极细原子命题相对，Sarthi 等人[7]（ICLR 2024）提出了 **RAPTOR**，先将文档按约 100 Tokens 切分为叶节点并由 SBERT[3] 编码，再结合 UMAP 降维与高斯混合模型（GMM）软聚类，递归调用大模型生成父节点抽象摘要，构建自底向上的多粒度语义树并采用“折叠树检索（Collapsed-Tree Retrieval）”平铺评估所有层级节点，在 QuALITY 基准上结合 GPT-4 取得了 $82.6\%$ 的准确率。此外，近期研究还提出了基于场景剖析与知识扩展的 **SPIKE**[27] 以及基于生成式 AI 派生高密度文档的 **RAIDD**[28]。
   **痛点与局限性**：上述依赖生成式大模型重写或递归摘要的方法在企业级工程文档上面临三大瓶颈：一是**计算超时与内存崩溃**，如 Śmigielski 等人[57]（2026）的实证评测所示，Dense X 等复杂生成式切片在长文档上极易发生执行超时（Timeout $T$）与底层分词库内存溢出（Memory Error $S$）；二是**破坏宏观叙事连贯性**，在 GutenQA 长篇基准上，Dense X 命题级切片的 DCG@20（$46.19$）与 Recall@20（$55.54\%$）甚至低于传统递归切分（DCG@20 为 $54.72$，Recall@20 为 $74.35\%$）[23]；三是**引入生成幻觉与破坏字面保真**，RAPTOR 作者在人工抽检的 40 篇故事共 150 个摘要节点中检出了 $4\%$（6 个节点）的轻微模型幻觉，且在 QuALITY 受控消融实验中 GMM 聚类树较简单连续切片递归树的准确率优势仅约 $0.8$ 个百分点（$56.6\%$ vs. $55.8\%$）[7]。对于要求条款措辞与表格字段零篡改的软件工程文档而言，生成式改写直接破坏了证据的可审计性。

2. **先编码后池化与长上下文嵌入路线（Late Chunking、LongEmbed、BGE-M3）**
   为了在不改写原文的前提下解决跨切片指代丢失问题，由汉肖（Han Xiao）等人领导的 Jina AI 团队 Günther 等人[15]（2024/2025）提出了**晚期切片（Late Chunking）**，颠覆了“先切片后独立编码”的传统流程：先将整篇长文档（或宏切片 Macro Chunk）一次性输入基于 **LongEmbed**[31] 扩展的支持 $8192$ Tokens 的长上下文编码器，获取蕴含全局自注意力上下文的 Token 级表征，再按切分边界在特征空间执行分段均值池化（Post-Chunking Mean Pooling）与 Span Pooling 微调，在 BeIR 句子级切分上取得了约 $3.63\%$ 的 nDCG@10 相对提升；智源研究院（BAAI）Chen 等人[16]（ACL Findings 2024）提出的 **BGE-M3** 则通过多粒度联合训练与自知识蒸馏兼顾了长短文本与词汇匹配。
   **痛点与局限性**：Late Chunking 的物理切分边界依然沿用固定 Token 数或静态标点；更重要的是，其原研实验表明，当目标证据是嵌入在大量无关背景中的孤立短句（如 Needle-8192 与 Passkey-8192）或采用大尺寸切片时，全局池化混入的无关长程背景反而会干扰局部特征（Over-Compression），导致性能劣于传统独立切片[15]；同时 $8192$ Tokens 的窗口仍无法单次覆盖包含数十份文档、数十万字的企业工程项目全集。

3. **逻辑与叙事边界探测及半结构化保真路线（LumberChunker、Meta-Chunking、MoC、HTML 保真切片）**
   为寻找符合人类认知的语义自然边界，Duarte 等人[23]（EMNLP Findings 2024）提出了 **LumberChunker**，按目标预算阈值（$\theta \approx 550$ Tokens）组织滑动段落组，通过指令提示大模型在线识别叙事转移点，在 GutenQA 上将 DCG@20 提升至 $62.09$、Recall@20 提升至 $77.92\%$。为摆脱对昂贵黑盒大模型的依赖，**中国人民大学信息学院与上海算法创新研究院（IAAR Shanghai）联合团队**（赵佳杰、李直谕、唐博、熊飞宇等）先后提出了 **Meta-Chunking**[24]（2024/2025）、发表于 ACL 2025 的混合切片学习器 **MoC（Mixtures of Text Chunking Learners）**[6]，以及清华大学与复旦大学团队提出的伪指令切片 **PIC**[5]（ACL Findings 2025）与复旦大学团队的 RAG 最佳实践评测[4]（EMNLP 2024）。其中，Meta-Chunking[24] 利用小尺寸语言模型（SLMs）计算句子级条件困惑度（Perplexity, PPL）序列的局部极小值点与边缘采样概率（MSP）探测逻辑边界，并辅以 KV Cache 滑动淘汰机制处理长文本；MoC[6] 则协同多个轻量级切片学习器平衡多尺度切分。在文档结构层，IBM 的 **Docling**[8]、属性图伪子图索引 **PG Indexing**[29]（在事实问答与多文档问答上提升 $3.34\% \sim 15.85\%$）以及 **面向 HTML 问答的结构保持上下文选择（Preserving Structure While Contextualizing Selections）**[30] 探索了保留原生层级与标签结构的切分方案。
   **痛点与局限性**：LumberChunker[23] 强依赖黑盒 LLM 串行在线推理，无法静态预建索引优化，且窗口扩至 $1000$ Tokens 时精度明显下滑；Meta-Chunking[24] 的一维句子条件困惑度在面对包含跨页二维表格、嵌套编号条款的半结构化工业文档时易受格式符号干扰，且其元切片动态合并阶段仍向单一静态目标长度妥协；而 HTML 结构保持方法[30] 专用于显式网页标签，尚未与企业 DOCX/XLSX 工程文档的“表头绑定行级子块 + 自适应章节父块”及下游智能体角色路由形成闭环。

### 1.2.2 自适应与多粒度检索增强生成研究现状

针对固定单次检索难以适应复杂查询的问题，2023–2026 年间的研究围绕“何时检索、检索何种知识源、如何自动寻优管线”发展出丰富的自适应 RAG 机制：

1. **自反思与多知识源单遍自路由（Self-RAG、SR-RAG、FLARE、IRCoT）**
   早期主动检索方法如 **FLARE**[40] 通过监测生成过程中低概率词元前瞻性触发重检索，**IRCoT**[41] 则将思维链（CoT）推理与多跳检索交织，但二者将所有查询视为同等复杂，在简单查询上易引入噪声且增加多智能体链路延迟。Asai 等人[32]（ICLR 2024）提出 **Self-RAG**，通过训练模型预测自反思特殊词元（Reflection Tokens，如 `Retrieve`、`IsRel`、`IsSup`、`IsUse`）实现按需检索与自我评判，在 PopQA 上提升约 $10$ 个百分点。进一步地，Wu 等人[38]（Findings of AACL 2026）提出 **自路由检索增强生成（SR-RAG）**，将选择性检索重构为“外部非参数化知识库 $S_e$ vs. 模型内部参数化知识显式口述（Knowledge Verbalization，$S_i$）”的多知识源选择问题，通过包含源交叉熵损失 $\mathcal{L}_{\text{src}}$ 的多任务学习，在单次自回归传递中减少 $21\% \sim 40\%$ 检索调用的同时将准确率提升 $2.1\% \sim 8.5\%$。
2. **基于查询复杂度分类、检索质量纠错与边际证据增益的动态路由（Adaptive-RAG、CRAG、Cost-Aware RAG）**
   Jeong 等人[33]（NAACL 2024）提出 **Adaptive-RAG**，利用轻量级查询复杂度分类器将查询动态路由至无检索、单步 RAG 或多步迭代检索；中国科学技术大学 Yan 等人[34]（2024）提出 **纠错型检索增强生成（CRAG）**，设计轻量级检索评估器对初检文档质量分级并触发细粒度知识提纯或 Web 搜索补充，在低质量检索环境下将准确率提升 $10\% \sim 15\%$，并在 PopQA、PubHealth 和 HotpotQA 上分别大幅超越智能体检索基线 **A-RAG**[51] 达 **$28.7\%$、$31.8\%$ 和 $10.7\%$**。近期研究[39]（2026）进一步从经济学权衡视角提出**成本感知的边际证据增益模型（Cost-Aware Marginal Evidence Gain）**，基于初次检索输出定量估计额外混合检索的边际收益；另有混合长上下文研究[42] 探索了多文档摘要中的最优上下文长度估计。
3. **RAG 管线超参数自动寻优框架（AutoRAGTuner、AutoRAG、AutoRAG-HP）**
   为替代人工调参，**AutoRAGTuner**[35]（2026）提出了声明式可演化 RAG 管线自动寻优框架；Kim 等人[36]（2024）提出 **AutoRAG**，将查询扩展、检索、段落增强（Passage Augmentation）与重排序模块化，采用贪心节点选择在 ARAGOG 基准上搜索最优配置；Fu 等人[37]（2024）提出 **AutoRAG-HP**，基于多臂赌博机（Multi-Armed Bandits）实现在线超参数调优。

**痛点与局限性**：现有自适应 RAG 研究存在明显的“**重步数路由、轻粒度路由，重问句表面特征、轻智能体角色先验**”倾向：Self-RAG[32] 与 CRAG[34] 高度依赖初始检索库中的固定段落切片质量，无法找回在初始切片阶段因跨块截断或表头剥离而漏检的证据；Adaptive-RAG[33] 与 SR-RAG[38] 虽建立了多策略/多源路由框架，但其外部知识库仍为同质化单层粒度，尚未在“细粒度表格行子块、父子混合上下文与粗粒度章节父块”之间实现按角色动态路由；而 AutoRAG[36] 与 AutoRAGTuner[35] 均以单一数据集的全局静态最优配置为目标，无法在同一多智能体长程任务内随异构角色的切换而逐跳改变父子融合权重。

### 1.2.3 多智能体协同记忆、子会话隔离与可验证评测研究现状

在多智能体协同与上下文工程领域，除早期的 ReAct[43]、Reflexion[44]、DSPy[45] 与 ADAS[46] 外，2024–2026 年间以**中国人民大学、北京航空航天大学、上海算法创新研究院及记忆张量（MemTensor）联合团队**为代表的国内外学者在智能体记忆演化、子会话隔离与可验证评测方面取得了一系列突破性进展：

1. **智能体记忆演化、幻觉评测与联想记忆（MemRL、HaluMem、Explicit Memory、HippoRAG2）**
   国内联合团队先后提出了集成显式外部记忆层的语言建模架构 **Explicit Memory**[53]（2024）、面向智能体记忆系统的幻觉生成与传播评测基准 **HaluMem**[48]（北航/人大/记忆张量，2025），以及基于运行时强化学习动态优化智能体情景记忆组织与检索的自演化框架 **MemRL**[47]（2026）；Gutiérrez 等人[52]（2025）则提出了仿生海马体跨片段联想记忆框架 **HippoRAG2**。其中，HaluMem[48] 的系统评测深刻揭示：**不当的记忆切片切分与有损摘要压缩是诱发智能体长期记忆幻觉并在多智能体链路中放大传播的核心诱因**，这为本论文坚持“原文保真、表头绑定、不依赖生成式改写”的确定性切片原则提供了直接的安全性依据。
2. **多智能体子会话隔离、分层缓存与切片局部复用（Hua & Xiao 2026、NativeScope、DoVer、Search-R1）**
   针对多智能体协同中的故障传播与过度检索问题，**DoVer**[54]（2026）提出了干预驱动的多智能体自动调试框架，**Search-R1**[55]（2025）通过离散检索动作空间抑制单智能体“过度思考（Overthinking）”。更具启发意义的是两项 2026 年最新实证研究：
   - **Hua 与 Xiao**[49]（2026）通过探针实验揭示了文档“已处理页面内容”与“实际消费切片”之间的巨大鸿沟，证实智能体子任务内部存在显著的**任务局部复用（Task-Local Reuse）**现象，按精准切片粒度投递比整页投递具有显著更高的单 Context Token 答案质量，并提出通过一次解析语料库状态构建**可共享检索状态（Shareable Retrieval State）与分层缓存（Hierarchical Caching）**；
   - **NativeScope**[50]（2026）探索了基于锚点坐标与原生关系的智能体**硬作用域限定（Hard Scoping）**记忆召回，但其受控实验暴露出严重的级联误差瓶颈——**当采用自动定位的 Top-1 锚点时，硬作用域直接继承了前端定位接口误差，导致记忆召回率暴跌至 $35.50\%$**。这一关键实证数据表明：机械的硬隔离极度脆弱，必须构建兼具父块全局兜底与子块精准匹配的软性多粒度融合与角色路由机制。
3. **切片边界质量、信息效率与可验证溯源评测基准（Śmigielski 2026、PEP-AI、SproutRAG、xFinder、xVerify）**
   在评测基准与可追溯治理方面，除软件需求追踪研究[9, 10, 26] 与 RAG 安全归因框架 Traceback[12]、IEEE S&P 2026[13]、TracLLM[14] 外，2024–2026 年涌现出针对切片粒度与成本折衷的专门基准：Śmigielski 等人[57]（Elsevier Procedia Computer Science, 2026）形式化定义了切片的“粒度–上下文折衷（Granularity–Context Trade-off）”，通过答案跨度（Answer Span）重叠评测揭示了各类切片算法的计算成本与崩溃边界；大规模多目标切片评测[58] 证明最优切片策略同时取决于嵌入模型、语料规模与运营成本；工业级 RAG 评测 **PEP-AI**[58]（2026）提出有界路由化上下文注入与单切片级合规审计，在 LoCoMo 上将累积证据召回率从 $55.5\%$ 提升至 $80.5\%$；**SproutRAG**[59]（2026）在科学、法律与开放域基准上将信息效率（Information Efficiency）平均提升 $6.1\%$；华人学者 Liu 与 Che[59]（2026）提出基于跨链哈希承诺（Hash Commitments）的可验证逻辑推理排序框架；北航与人大团队推出的 **xFinder**[60]（2024）、**xVerify**[60]（2025）以及数值核查基准 **QuanTemp**[60]（2024）则进一步完善了复杂推理与数值声明的核验工具链。

* **第 3 章切入点（面向半结构化工程文档的“结构保真 + 关键信息感知”零幻觉父子动态切片 SEAC）**：针对 Dense X[22] 与 LumberChunker[23] 调用生成模型重写带来的超时风险[57]与原文失真、RAPTOR[7, 48] 递归摘要带来的 $4\%$ 微幻觉风险，以及通用语义切片在表格与标题交界处的误切问题，本文第 3 章吸收结构保持切片[8, 30]与逻辑边界感知[24]思想，在不调用生成式大模型改写原文的前提下，融合相邻单元稠密语义距离、章节/表格组结构转移、工程关键信息密度变化与连续性惩罚，通过根据文档表格行率与标题率计算的动态阈值 $\theta_D$ 生成“表头绑定的细粒度表格行/句段子块 + 章节保护的多档自适应父块”双层无幻觉索引。
* **第 4 章切入点（面向多智能体异构角色与子会话隔离的单索引动态检索粒度选择 MAS-DRG）**：针对 Adaptive-RAG[33] 与 A-RAG[51] 忽视智能体角色异质性、以及 NativeScope[50] 自动硬作用域隔离导致召回率暴跌至 $35.50\%$ 的缺陷，本文第 4 章吸收 SR-RAG[38] 多源路由、Cost-Aware 边际证据增益[39]与 Hua & Xiao[49]（2026）“一次解析语料库、构建可共享检索状态按需投递切片”的核心思想，在 SEAC 单一层次化索引上将智能体角色职责先验映射为三类信息需求模型，在查询阶段动态路由父子排序融合权重 $\alpha$ 与上下文返回模式（仅子块、父子混合、仅父块），以软性父子融合与按需裁剪完美替代脆弱的硬作用域隔离。

## 1.3 主要研究内容与创新点

### 1.3.1 主要研究内容

本论文围绕企业软件工程文档在多智能体检索增强生成系统中的“高质量切片、动态粒度匹配与可追溯应用”展开，总体研究内容由三项紧密递进的核心部分组成（三项研究内容的逻辑演进关系如图 1-1 所示，矢量文件见 [fig1_1_research_framework.svg](file:///Users/apple/Desktop/毕业设计/小论文/毕业论文/figures/fig1_1_research_framework.svg)）：

1. **研究内容一：面向企业工程文档的结构与关键信息感知自适应语义切片算法研究（第 3 章）**
   深入剖析企业软件工程文档（需求、接口、数据库字典、技术协议、会议纪要）的结构特征与传统切片的三类失效机理。定义携带稳定出处标识（Unit ID）的文本单元表示与表头绑定渲染公式；融合相邻单元稠密语义距离、章节与保护组结构转移、工程关键信息词表密度变化以及连续性惩罚，设计透明可解释的边界打分函数；提出基于文档表格行占比与标题占比的**文档级自适应阈值**与四档容量父块组装算法，并构建“细粒度行/句段子块触发—连贯父块回传”的层次化检索模型。在包含 10 个企业软件项目、89 份文档、66,981 个检索单元的冻结工业基准上开展 15 种方法的全面对比与消融实验。
2. **研究内容二：面向智能体角色的动态检索粒度选择方法研究（第 4 章）**
   针对第 3 章消融实验揭示的“全局固定父块融合权重（$\alpha=0.35$）在原子表行检索上稀释信噪比、而在接口关联检索上又不可或缺”的核心矛盾，结合详细设计多智能体系统的层级架构，将系统中的五类业务智能体建模为**精确事实型（$T_{\text{atomic}}$）**、**层次上下文型（$T_{\text{hier}}$）**与**上下文概述型（$T_{\text{macro}}$）**三类异构信息需求。提出一种基于 SEAC 单一层次化索引的**角色感知动态检索粒度选择架构（MAS-DRG）**，在查询阶段根据智能体角色先验动态查表路由父子融合权重 $\alpha \in [0, 1]$ 与上下文返回模式（仅子块、父子混合、仅父块），在零额外索引存储开销的前提下同时优化检索精度与返回上下文的 Token 经济性。
3. **研究内容三：在多智能体详细设计文档生成系统中的架构集成与案例验证（第 5 章）**
   研究面向企业软件项目的《多智能体详细设计文档自动生成系统》的三层工程架构（`Multi-Agent-Framework` 框架层、`Multi-Agent-DetailedDesign` 应用层与 `binary-tools` 编译工具层），剖析其基于 Manager 单例、配置驱动、父子会话层级调度（`session_create` / `session_query`）与 Typst/PlantUML/Mermaid 编译工具链的文档生成工作流。针对系统原有“全文读取 + 摘要传递”模式在长文档上下文截断、细节规则丢失与无法溯源方面的局限，设计基于 SEAC 与 MAS-DRG 角色路由的可追溯知识检索服务接口（`rag_query`），并通过从真实历史会话日志中抽取的典型协调层与执行层智能体请求开展离线对比案例分析与系统产出展示。

### 1.3.2 主要创新点

本论文的核心创新点主要体现在以下两个算法与架构层面（辅以一项工业评测与系统落地贡献）：

1. **创新点一（文档级动态切片创新）：提出结构与关键信息感知的自适应语义切片算法（SEAC）**
   针对传统固定窗口与通用语义切片在表格密集型软件工程文档上易发生结构断裂、表头剥离与出处丢失，以及大模型重写/递归摘要切片存在计算超时与微幻觉[7, 48, 57]的问题，设计了携带稳定单元出处标识与表头显式绑定机制的零改写文本表示模型；首次将相邻句向量余弦距离、文档语法结构转移、领域关键信息密度变化与同节/同表连续性惩罚统一于确定性透明边界打分框架中，并提出根据文档自身表格行比例与标题比例动态调整切分阈值的自适应机制。在 10 个真实工业项目上的冻结实验证明，该算法在锁定测试集上取得 $0.5673$ 的边界 F1、$0.7937$ 的 Unit MRR 与 $0.9520$ 的 Hit@5，显著超越固定窗口、递归切分、通用语义切片以及 LangChain、LlamaIndex 官方切片器（相关成果已形成学术论文被 IEEE 国际会议 ICAISG 2026 录用）。
2. **创新点二（角色级动态检索创新）：提出基于单索引的面向多智能体角色动态检索粒度选择方法（MAS-DRG）**
   针对多智能体系统中不同层级角色（执行层数据库/约束智能体、模块层接口智能体、协调层概述/流程智能体）信息需求粒度异构、单一静态融合参数无法兼顾各角色性能且机械硬作用域隔离易引发召回崩溃[50]的问题，摈弃了传统多粒度方案需重复构建 $N$ 套冗余索引库的高成本做法，提出在 SEAC 可共享单一父子层次化索引[49]上解耦“排序融合权重 $\alpha$”与“上下文返回模式”的查询级动态路由机制。实验证明，由开发/验证集标定的角色动态路由策略在未见过的锁定测试集上将整体 Unit MRR 进一步提升至 **$0.8416$（Hit@1 达 $0.7520$，召回优先策略 Hit@5 达 $0.9600$）**，在开发验证集与锁定测试集上双双击败所有全局静态单一配置，同时将单次查询平均返回的上下文 Token 开销降低了 **$35.8\%$**（较固定窗口降低 **$72.2\%$**）。

## 1.4 论文组织结构

本论文共分为六章，各章节之间的逻辑脉络与技术路线如图 1-2 所示（矢量文件见 [fig1_2_thesis_structure.svg](file:///Users/apple/Desktop/毕业设计/小论文/毕业论文/figures/fig1_2_thesis_structure.svg)），各章主要内容安排如下：

* **第 1 章 绪论**：阐述大语言模型与检索增强生成在企业级多智能体文档生成系统中的研究背景，剖析静态文本切片与多智能体动态异构需求之间的核心矛盾，系统综述 2020–2026 年间国内外在半结构化语义切片、自适应与多粒度 RAG、多智能体角色记忆隔离及可验证评测基准方面的 60 项代表性研究，明确本文的三项主要研究内容、两项核心创新点及论文整体组织结构。
* **第 2 章 相关理论与技术基础**：系统梳理支撑全文研究的四大理论支柱，包括检索增强生成（RAG）数学形式化、大模型注意力头聚焦机理、选择性自路由与边际证据增益、双塔稠密向量检索与 BGE-M3 多粒度嵌入模型及 Chroma 向量数据库原理；主流文本切片方法（固定窗口、递归切分、句子切分、结构切分、余弦距离语义切片、先编码后池化 Late Chunking、条件困惑度逻辑感知切片 Meta-Chunking 与父子层次检索）的数学建模与优缺点对比；基于大语言模型的多智能体系统（工具调用、情景记忆演化、硬作用域隔离级联误差分析与信息需求异构性）；以及检索与边界评价指标、分层 Bootstrap 置信区间、项目簇精确置换检验、Holm 多重检验校正与 Cohen's $\kappa$ 系数等统计推断理论。
* **第 3 章 结构与关键信息感知的自适应语义切片算法**：对应本文**第一项核心创新点（文档级动态切片）**。分析企业工程文档的四大特征与传统切片的三类失效案例，详细阐述 SEAC 算法的携带出处文本单元表示、四信号透明边界打分公式、文档自适应阈值 $\theta_D$、受保护自适应父块与表格行子块构建规则以及父子融合检索算法，并在 10 个企业项目的冻结工业基准上报告检索质量、边界质量、单组件消融、时空成本与项目级不确定性分析。
* **第 4 章 面向智能体角色的动态检索粒度选择**：对应本文**第二项核心创新点（角色级动态检索）**。基于第 3 章消融实验揭示的固定融合权重局限性，归纳详细设计多智能体系统的五类智能体角色与三类信息需求模型，设计基于 SEAC 单一索引的角色感知动态粒度选择方法（MAS-DRG），通过开发/验证集标定与锁定测试集盲测，全面评估动态路由在检索精度（MRR、Hit@$k$）与上下文 Token 经济性上的综合增益。
* **第 5 章 多智能体详细设计文档生成系统中的应用**：阐述企业软件项目详细设计文档自动生成系统的三层总体架构、多智能体框架核心抽象与父子会话层级编排工作流，设计基于 SEAC 与角色动态路由的 `rag_query` 检索知识服务接入方案，并通过真实历史会话请求开展固定窗口、SEAC 静态配置与 SEAC 角色动态路由的离线案例定性对比分析与系统生成文档展示。
* **第 6 章 总结与展望**：全面总结全文围绕“文档级自适应语义切片”与“角色级动态粒度路由”所取得的研究成果与核心量化指标，客观剖析当前研究在语料领域覆盖面、项目簇统计功效及在线端到端闭环评估方面的局限性，并对学习型连续路由、多模态工程图纸解析及在线多智能体深度集成等未来研究方向作出展望。
