判定口径

表内相邻行
同一张表的表头与数据行、相邻数据行，一律 NO_BREAK。行级检索由子块处理，不用父块边界拆表。
标题
标题本身不等于断点。「上一主题 → 新标题」判 BREAK；「新标题 → 它的首段」判 NO_BREAK。
长度
不得因为文本接近或超过 512 token 就判 BREAK。长度由切块器处理，你评的是语义边界。
短文本
内容短不等于噪声。接口方法名、字段名、约束值仍是有效证据。
歧义
拿不准时填最佳判断，勾「标为歧义」并写明来源，不要留空。这些行仍计入一致率。

快捷键

  • n 聚焦备注框 · Esc 离开备注框 · ? 开关本页
