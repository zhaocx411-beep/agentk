# ChinaSoft 2026 IISE 投稿包说明

## 当前结论

论文正文已经按照《计算机学报》Word 模板整理为 A4 双栏 18 页，内容包括中英文题名与摘要、6 个中英文关键词、10 节正文、方法流程图、8 张正文表、4 张附录表、23 条参考文献、英文 Background、作者简介位置以及人工智能使用声明。公式、表格、分页、字体和页边距已经逐页渲染检查。

论文的专题匹配度较高：研究直接面向“大模型驱动的工业软件工程开发、保障与治理”，核心贡献是带来源标识的结构保持分块、细粒度检索、证据审计和治理接口；实验同时报告正面、负面和资源开销结果，没有把未达到 0.05 的项目级检验描述为一般统计优越性。

## 文件用途

- `SEAC_ChinaSoft2026_IISE_署名待填.docx`：可编辑署名版。红色字段必须补齐后才能投稿。
- `SEAC_ChinaSoft2026_IISE_署名待填.pdf`：署名版排版预览，不能直接上传。
- `SEAC_ChinaSoft2026_IISE_匿名备份.docx`：匿名可编辑备份。
- `SEAC_ChinaSoft2026_IISE_匿名备份.pdf`：如果投稿页面明确要求匿名稿，上传这一份。
- `EasyChair_投稿元数据.md`：题名、摘要、关键词、专题和给主席说明，可直接复制。
- `投稿信息与上传清单.md`：从登录 EasyChair 到保存回执的操作清单。
- `作者信息待补充.md`：请按该格式提供作者、单位、通信和基金信息。
- `author_metadata.json`：生成署名稿所读取的作者元数据。
- `paper_zh.md`：完整论文源稿。
- `reference/`：官方投稿说明、原始 Word 2003 模板及转换后的分析副本。
- `validation/`：无障碍、样式和最终验收记录。

## 上传版本判断

专题公开征稿没有明示双盲要求，因此默认应在补齐作者信息后上传署名 PDF。只有当 EasyChair 页面或专题秘书明确要求匿名评审时，才上传匿名备份。不要同时上传两份 PDF，也不要把文件名含“待填”的版本上传。

## 唯一待办

目前只缺真实作者元数据。收到 `作者信息待补充.md` 所列信息后，重新生成无红字的署名终稿并做一次最终渲染即可投稿。
