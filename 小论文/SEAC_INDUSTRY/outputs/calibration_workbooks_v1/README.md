# SEAC boundary calibration workbooks (private)

This directory contains 30 development-only P01 boundary cases. Six cases were
originally disagreements and were resolved during P01 adjudication. The sample
covers all nine observed combinations of boundary type and final label.

1. Give `SEAC_boundary_calibration_exercise.xlsx` separately to annotators A
   and B. They complete `trainee_label` and `trainee_rationale` independently.
2. Keep `SEAC_boundary_calibration_key.xlsx` with the annotation coordinator
   until both exercises are returned.
3. Compare the completed exercises with the key and discuss decision rules only.
4. Begin P02–P10 formal annotation independently; calibration rows never enter
   formal test metrics.

These workbooks contain enterprise-derived text. Do not publish them, upload
them to a general-purpose annotation service, or include them in the anonymous
review artifact. File hashes and the frozen selection are recorded in
`calibration_manifest.json`.
