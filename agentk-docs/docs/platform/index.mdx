# AgentK Platform

AgentK Platform 是 Runtime 之上的长期产品方向，目标是把管理、试验、快速原型和部署
实例化收进一个统一入口。

:::warning[规划中]

Platform 尚未作为稳定产品交付。本页只是信息架构占位，以下能力均为 **TBD**，不代表
当前环境已经提供对应页面、API 或部署流程。

:::

## Admin — TBD

面向 AgentK 接入方和平台管理员的配置、身份、权限、资源与运行状态管理。

## Playground — TBD

交互式选择模型、<Profile />、<Capability /> 和输入，快速验证 Agent 行为、<Pipeline /> 输出与
事件流。

## Fast Prototyping — TBD

从已有模型与 Capability 组合 Agent 原型，调试 Profile，并把可运行配置沉淀为可复用
定义。

## Deploy & Instantiate — TBD

把经过验证的 Agent 定义部署或实例化到目标环境，管理版本、配置和运行边界。

Platform 管理的是 AgentK 接入方、应用身份和 Agent 资源；下游应用的终端用户、会员、
偏好及其到 <Session /> 的映射仍由下游应用自己管理。
