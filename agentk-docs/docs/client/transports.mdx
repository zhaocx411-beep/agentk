# 选择 Client transport

生产服务使用 KESS gRPC h2c transport。Client SDK 通过 KESS 发现 AgentK 实例，应用无需配置
固定地址或自行拼接 RPC 路径。

运行前向 AgentK 平台维护方登记工作负载 KSN，并完成 Service/App 绑定。本机连接 staging 时设置：

```bash
export KWS_SERVICE_NAME='<registered-ksn>'
```

部署环境由平台注入 KWS 身份。Client SDK 在构造时读取环境，并对 unary 和 server-streaming
请求使用相同的接入身份。

## KESS gRPC h2c

适合能够访问 KESS 和 AgentK 实例网络的服务。Client 通过 KESS 发现
`klingai-agentk-api`，再使用未加密 HTTP/2 直连所选实例。

```text
应用 → KESS 发现 → AgentK 实例 IP:Port → gRPC h2c
```

Go：

```go
client, err := agentkgrpc.New(agentkclient.Options{})
```

Python：

```python
client = agentk.client.grpc.create_client(Options())
```

Java：

```java
AgentKClient client = AgentKGrpcClient.create(new ClientOptions());
```

本机 KESS Agent 只与 staging 联通。生产 gRPC smoke 和生产服务必须运行在能够发现生产 KESS
服务的 IDC 环境。

## 固定 endpoint

本地调试或明确的独立部署可以覆盖 transport 的默认 endpoint。endpoint 必须是包含 scheme 和
authority 的绝对 URL：

```go
client, err := agentkgrpc.New(agentkclient.Options{
    Endpoint: "http://127.0.0.1:8080",
})
```

```python
client = agentk.client.grpc.create_client(
    Options(endpoint="http://127.0.0.1:8080")
)
```

```java
AgentKClient client = AgentKGrpcClient.create(
    ClientOptions.forEndpoint("http://127.0.0.1:8080"));
```

endpoint 只选择连接目标，身份传播行为保持一致。需要非 KESS 的生产连接时，向 AgentK 平台维护方
提供部署环境和网络路径，由平台确认接入地址。
