# API Reference

API Reference 从 Client SDK 与 Worker SDK 的公开代码 API 和源码注释生成，按包、类型、函数
与方法提供符号级查询。它不由手写 SDK 说明替代，也不复述指南中的使用流程。

## Go

- [Client API](/reference/go/client)：Session、Execution 与 KESS gRPC transport。
- [Worker API](/reference/go/worker)：Capability、Temporal、进度上报与 Worker。
- [Protocol types](/reference/go/protocol)：Go SDK 暴露的 protobuf message、enum 与 oneof。

## Python

- [Client API](/reference/python/client)：Session、Execution 与 transport client。
- [Worker API](/reference/python/worker)：Capability、Tool、进度上报与 Worker。
- [Protocol types](/reference/python/protocol)：Python SDK 暴露的 protobuf message 与 enum。

## Java

- [Client API](/reference/java/client)：Session、Execution 与 KESS gRPC transport；KS Boot artifact 使用相同的公开 API。
- [Protocol types](/reference/java/protocol)：Java SDK 暴露的 protobuf message、enum 与 Connect service 类型。
